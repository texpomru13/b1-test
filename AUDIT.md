# Проверка решения по ТЗ

Сервис принимает PDF и DOCX, индексирует их в фоне и отвечает на вопросы по выбранному документу. Приёмка охватывает загрузку, поиск, полноту ответа, точность цитат и восстановление после остановки. [Запуск и примеры запросов](README.md)

## Корпус и смысловая оценка

В едином корпусе **27 реальных документов и 323 вопроса**. По 14 договорам размечены 133 вопроса, по семистраничному скану договора о виртуальной АТС — десять. 180 вопросов с подробной разметкой охватывают 18 PDF о договорах организаций, официальных публикациях, офертах и тарифах. Шесть документов участвуют в обеих разметках и учитываются по одному разу в числе 27. Для 220 вопросов предусмотрены ответы, для 103 ожидается отказ. Синтетические PDF служат для контролируемых проверок таблиц и исключений. [Каталог всех файлов](test_documents/README.md) · [Все вопросы и эталоны](eval/gold/questions.md)

Через один публичный API заданы **210 разных вопросов по всем 27 документам** и выполнены **18 проверок изоляции**. В выборку вошли все 180 тематических вопросов и по одному положительному и отрицательному вопросу по каждому из 15 пронумерованных файлов. На 125 из 135 вопросов с ответом сервис выдал результат. В 74 из 75 случаев отсутствия сведений и во всех 18 пробах с чужим документом сервис вернул отказ. Все 228 откликов соответствуют схеме HTTP 200. Для всех 262 цитат совпали документ, текст, страницы и координаты. [Выборка и показатели по каждому документу](eval/reports/catalog/README.md) · [Идентификаторы вопросов](eval/gold/acceptance-plan.json)

Для независимой смысловой оценки выбраны публичные оферты и тарифы. Код, документы и эталоны зафиксировали до первого запроса. Для каждой тематической подборки пороги составляют 90% обязательных фактов и условий, 85% полностью корректных ответов, ноль критических искажений, 20/20 отказов при отсутствии сведений и 6/6 при подмене документа. В знаменатель полноты входят все 40 вопросов, для которых ответ есть в PDF. Сверка человеком остаётся открытой. В 30 вопросах по пронумерованным договорам полностью даны 9/15 положительных ответов, ещё пять неполны, один завершился отказом. На все 15 отрицательных вопросов сервис ответил отказом с пустым списком цитат. Например, в договоре поставки названа ежедневная пеня, но пропущено исключение при неисполнении обязательств поставщиком. При сверке ассистентом по четырём сериям в сумме полностью корректны **99 из 135** положительных ответов. [Разбор по каждому из 15 договоров](eval/reports/catalog/numbered-review.md)

На офертах Qwen засчитала в четырёх ответах детали, которые можно прочитать в источнике, но сервис пропустил в тексте. Например, гостиница требует письменного уведомления об отмене бронирования, а музей указывает день недели для экскурсии. При проверке по явно сообщённым фактам пороги по полноте не достигнуты. Среди договоров есть ошибка выбора раздела: в ответе про кран сервис указал 1,5 т по форме акта вместо 3 т по пункту об арендной плате. В официальных публикациях одно из искажений изменило событие, от которого отсчитывается срок. [Оценка утверждений по офертам](eval/reports/offers/crosscheck-claims.json)

Задержку измерили на одном прогретом API по 66 последовательным запросам из выборки оферт. Медиана составила **17,2 с**, 95-й процентиль — **29,7 с**, максимум — **61,0 с**. Для реранжирования на CPU медиана составила 9,3 с. Судья приступил к оценке после последнего измерения. [Протокол замера и настройки](eval/reports/offers/README.md)

## Повторная проверка полноты

На той же модели и тех же индексах выполнили 67 HTTP-запросов. Из 36 прежде неполных положительных ответов исправлен 21, а все 30 случайно выбранных полных ответов сохранили полноту. На тех же 66 вопросах число полных ответов выросло с 30 до 51. На отдельный вопрос о максимальной мощности сервис корректно вернул отказ без цитат. По Европейской конвенции полными стали все три прежних отказа и сохранились оба контрольных ответа. Шестой положительный вопрос по Конвенции в повторную выборку не вошёл. [План, оценки по группам и все оставшиеся ошибки](eval/reports/completeness/README.md) · [Вопросы по Конвенции и страницы PDF](eval/reports/completeness/series/published-six/ECHR.md)

Оценочное число полных ответов по всем 135 положительным вопросам — 120 (88,9%) при измеренных ранее 99 (73,3%). Повторно проверены 66 положительных вопросов, 69 остались за пределами выборки. В этой серии 66 из 67 запросов завершились HTTP 200. Для вопроса о реестре космических объектов модель дважды выдала ответ, который не прошёл валидацию, и API вернул HTTP 502. Проверена 151 выданная цитата. Во всех случаях документ, текст, страницы и координаты совпали с индексом. Смысловая сверка выполнена ассистентом. [Сводка по сборке и метод оценки](eval/reports/completeness/result.json)

По итогам разбора оставшихся 15 ошибок повторён 31 HTTP-запрос на сборке `66ba699`. Проверены все 15 проблемных и 16 случайных из 51 полного ответа предыдущей серии. На тех же вопросах число полных ответов выросло с 16 до 31. Сервис вернул HTTP 200 во всех случаях, все 65 обязательных фактов и условий переданы, все 68 цитат сверены по тексту, документу, страницам и координатам. [Причины, результаты и метод повторной проверки](eval/reports/resolution/README.md)

## Контрольные вопросы по договорам

Через HTTP API прошли четыре контрольных вопроса и все 16 проверок содержания. Все 11 цитат совпали с текстом, страницами и координатами в документе. Вопросы по договорам включены в разработческие тесты. [Ответы и манифест стенда](eval/reports/regressions-final/README.md)

| Что проверялось | Подтверждённый ответ |
|---|---|
| Область действия акции | Камера 4G стоит 6 600 рублей с НДС при единовременной оплате. Промопериод — не более 14 календарных дней от подключения. |
| Запрет и исключение | Субсубподряд запрещён. Исключение требует и специализированных работ, и согласования с заказчиком. Штраф — 100 000 рублей за каждый случай. |
| Условие гарантии | Данные на оборудовании исполнителя сохраняются 14 дней с приостановления. После этого допускается автоматическое безвозвратное удаление. |
| Управляющий пункт на другой странице | Запрет перепродажи охватывает услуги исполнителя и отдельно поддержку VDS, в том числе передачу паролей и перепродажу через API. |

Разбор 13 отказов по договорам содержит вопрос, нужные доказательства, этап отказа и ожидаемый результат. Проверка на фиксированном контексте позволяет установить, какие сведения теряются уже после отбора фрагментов. ## Работа со сканами

Семистраничный договор о виртуальной АТС распознан локальным Tesseract и проиндексирован в 102 фрагмента. В смешанном PDF текстовая страница прочитана напрямую, распознана только страница с изображением. Сервис вернул срок «5 календарных дней со дня акцепта» и дословную цитату с физической страницы 2. В карточке документа и в цитате доступно поле `ocr_pages`. [Изображение пункта, ответ и координаты](eval/reports/ocr-acceptance/README.md)

## Запуск и надёжность

На macOS 26.7.3, Apple M4 Max, 128 ГиБ памяти профиль `balanced` с пустыми хранилищами моделей вышел в готовность за **7 минут**. Кэши весов заняли 9,15 ГиБ. Слои Docker были доступны локально. После остановки запуск с `--offline` занял **15 секунд**. Оба договора из демо остались доступны. [Ход проверки и сценарий воспроизведения](eval/reports/cold-start/README.md)

| Требование | Реализация и проверка |
|---|---|
| Загрузка, статус и список документов | HTTP 202 со ссылкой на задачу. Пример загружает два договора, ожидает индексации и проверяет список. [Демо](eval/demo.sh) |
| До 100 физических страниц | Воркер проверяет размер PDF до OCR. DOCX преобразуется в постраничный PDF с помощью LibreOffice. [Обработка PDF](app/ingestion/pdf_loader.py) |
| Единая коллекция и гибридный поиск | Qdrant фильтрует по документу и опубликованной попытке, объединяет dense и BM25. Реранкер получает название области и управляющие условия до отбора контекста. [Поиск](app/retrieval/search.py) · [Проверка фильтров и публикации](tests/integration/test_published_storage.py) |
| LangChain и цитаты | LangChain участвует в разбиении, построении эмбеддингов и вызовах LLM. Сервер восстанавливает текст, страницы и координаты по идентификаторам доказательств. [QA](app/qa/workflow.py) · [API-контракт](app/schemas/qa.py) |
| Изоляция, повторы, надёжная публикация | Предусмотрены ограниченные повторы при временных сбоях. Только владелец активной попытки может опубликовать индекс. [Проверки восстановления](tests/integration/test_recovery_faults.py) · [Повторная доставка](tests/integration/test_requeue_redis.py) |

Локально прошли 326 модульных тестов и 10 интеграционных тестов с настоящими Redis и Qdrant, без пропусков. Прошли Ruff, mypy, проверки трёх lock-файлов и конфигураций Compose. Для push и pull request настроено отдельное задание с настоящими хранилищами, которое завершается ошибкой при пропуске обязательной проверки. [Workflow CI](.github/workflows/ci.yml)

## Границы применения

Точные координаты позволяют проверить источник. Правильность распознанных букв и цифр в скане сверяется с изображением. Полнота сложного ответа и применимость каждого условия проверяются по вопросу и соответствующему разделу документа. Стенд с реальными моделями испытан на macOS и Apple Silicon. Для работы с документами клиентов нужны разграничение доступа, политика хранения, резервное копирование и мониторинг очереди.
