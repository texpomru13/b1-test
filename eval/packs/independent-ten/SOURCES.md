# Источники для независимой оценки

Первичные русскоязычные публикации. Номера страниц в разметке относятся к сохранённым PDF. Для Договора о законах по товарным знакам 1994 года взяты физические страницы 1–47 издания ВОИС. Они содержат весь текст договора. Следующая часть издания посвящена инструкции. У остальных PDF сохранены опубликованные файлы. [Все 10 PDF](../../../test_documents/independent-ten)

Сборка приложения зафиксирована в `9210fc3` до подготовки вопросов. В каждом документе шесть вопросов с ответом и два вопроса об отсутствующих сведениях. Ещё десять запросов проверяют изоляцию подменой документа. Вопросы, факты и координаты эталонов сверяются по [листу для проверяющего](source-review.md). Содержательную оценку ответов проводят после получения полного прогона.
