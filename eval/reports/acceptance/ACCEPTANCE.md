# Проверка запуска и сохранности данных

На MacBook Pro M4 Max профиль `balanced` вышел в готовность за 8 минут 6 секунд с пустыми хранилищами моделей. Демо через публичный API загрузило два договора и проверило поиск, цитаты, отказ и изоляцию. После остановки сервис поднялся из кэша за 15 секунд. Оба документа сохранились в списке и были готовы для запросов. [Протокол запуска, команды и параметры машины](../cold-start/README.md)
