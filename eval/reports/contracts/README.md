# Договоры организаций

Через публичный API задано 60 вопросов о шести договорах и шесть проб изоляции. Ниже отражено решение сервиса ответить или отказаться, а также проверка источников. Полнота обязательных сведений и корректность выданных утверждений разобраны [по текстам ответов](REVIEW.md). [Лист сверки с PDF](../../packs/contracts-six/source-review.md)

| Проверка | Результат |
|---|---:|
| Сервис выдал ответ на вопрос с доказательствами | 40/40 |
| Сервис отказал при отсутствии сведений | 19/20 |
| Сервис отказал при вопросе к чужому документу | 6/6 |
| Валидные ответы HTTP 200 | 66/66 |
| Дословные цитаты с верными координатами и страницами | 100/100 |

[Сырые ответы](responses.jsonl) · [Манифест](manifest.json) · [Метрики](metrics-all.json) · [Контрольные суммы](sha256.json)

Для пересчёта механических метрик на сохранённых HTTP-ответах из корня проекта выполните команды.

```sh
export B1_EVAL_WORK_DIR="$(mktemp -d)"
REPORT="$PWD/eval/reports/contracts"
tar -xzf "$REPORT/inputs.tar.gz" -C "$B1_EVAL_WORK_DIR"
mkdir -p "$B1_EVAL_WORK_DIR/runs/final"
cp "$REPORT/responses.jsonl" "$REPORT/manifest.json" "$B1_EVAL_WORK_DIR/runs/final/"
uv run --frozen python eval/metrics.py --run final
```
