**Полностью корректны 32 из 40 положительных ответов при пороге 34.** Сервис выдал ответы на все 40 положительных вопросов. ## Какие ответы меняют смысл источника

- **Кран-балка, `contract-04-02`.** В пункте 1.1 договора указаны грузоподъёмность **3 т** и включённое в арендную плату использование по прямому назначению. В форме акта приёма-передачи того же помещения напечатано **1,5 т**. Сервис взял грузоподъёмность из формы, условие оплаты из договора и подал всё как единую характеристику. Число 1,5 т действительно есть в PDF. В ответе требовалось отнести 3 т к пункту 1.1 и оговорить расхождение с приложением. [Договор, стр. 1](../../../test_documents/04_Аренда_производственного_помещения.pdf#page=1) · [Форма акта, стр. 9](../../../test_documents/04_Аренда_производственного_помещения.pdf#page=9)
- **Часы возврата оборудования, `contract-05-07`.** Для возврата оборудования «Оптибит» устанавливает рабочее время и срок в одни сутки с момента обращения. Обе части сервис передал верно. Затем он указал интервал 08:00–17:00. Этот интервал приведён у телефона приёмной в разделе о техподдержке. Пункт о возврате оборудования такого интервала не устанавливает. [Оферта, пп. 4.6 и 6.6, стр. 3](../../../test_documents/05_Хостинг_Оптибит.pdf#page=3)
- **Смена редакции условий стройподряда, `contract-07-04`.** Правило о сохранении договорной редакции и переходе на другую по соглашению сторон передано верно. Дополнительное утверждение распространило пятидневную процедуру из пункта 13.14.1 на изменение общих условий. Она относится к препятствиям выполнению работ, например дефектам технической документации. Смена редакции регулируется пунктом 4.2. [Договор, стр. 2](../../../test_documents/07_Строительный_подряд_Метафракс.pdf#page=2) · [Стр. 21](../../../test_documents/07_Строительный_подряд_Метафракс.pdf#page=21)

Один отрицательный вопрос, `contract-04-08`, спрашивал о **максимальной** электрической мощности помещения. Сервис ответил, что разрешённая нагрузка должна быть **не менее 50 кВт**. Это подтверждённый нижний предел. Максимум договор не указывает, поэтому для этого вопроса ожидался отказ. [Договор аренды, стр. 3](../../../test_documents/04_Аренда_производственного_помещения.pdf#page=3)

В двух последних строках возможна более мягкая оценка. Если считать ежедневную съёмку в ходе работ достаточным указанием на весь период и принимать ссылку из соседнего утверждения, число полностью корректных ответов увеличится на два. Ни одна из этих трактовок не устраняет три существенные ошибки или ответ на вопрос о максимальной мощности.

## Пересчёт по сохранённым ответам

В установленном окружении проекта запустите из корня репозитория. Команды сверят эталоны с PDF и экспортом индекса, заново рассчитают технические показатели и применят сохранённые решения проверяющего.

```sh
report="$PWD/eval/reports/contracts"
export B1_EVAL_PACK=contracts-six
export B1_EVAL_WORK_DIR=$(mktemp -d)
tar -xzf "$report/inputs.tar.gz" -C "$B1_EVAL_WORK_DIR"
run="$B1_EVAL_WORK_DIR/runs/final"
mkdir -p "$run"
cp "$report/manifest.json" "$report/responses.jsonl" "$report/claim-review.json" "$run/"
uv run --offline --frozen python eval/qualification_data.py --check-index
uv run --offline --frozen python eval/metrics.py --run final
uv run --offline --frozen python eval/qualification_review.py score --run final
cmp "$run/qualification.json" "$report/qualification.json"
```
