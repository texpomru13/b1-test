## Контрольные вопросы

- **Ставка для каждого срока вклада**. Для срока от 91 до 180 дней справочный показатель средней максимальной ставки по вкладам составляет 15,15%. [1] Для срока свыше 1 года справочный показатель средней максимальной ставки по вкладам составляет 15,05%. [1]
- **Исключение для СМИ в отношении олимпийского символа**. (4) Ни одно государство-участник настоящего Договора не обязано запрещать использование олимпийского символа, если он используется средствами массовой информации в целях информации об олимпийском движении или о деятельности, осуществляемой в рамках этого движения. [1]
- **Орган, принимающий решение о созыве конференции**. Решение о созыве конференций по пересмотру принимается Ассамблеей. [1] Ассамблея дает Международному бюро указания относительно подготовки конференций по пересмотру. [2] Международное бюро подготавливает конференции по пересмотру положений Соглашения, за исключением статей 5-8. [3][4]

Три контрольных запроса выполнены первым этапом, остальные 63 — после HTTP-серии по офертам. Часть запросов второго этапа обрабатывалась одновременно с локальной смысловой оценкой оферт. Приведённая задержка характеризует эту нагрузку. Изолированный замер приведён в [отчёте по офертам](../offers/README.md).

В [результатах контроля](controls.json) сохранены вопросы, ответы, координаты и отдельные критерии. При проверке валидатора подстановка ставки соседнего диапазона должна отклоняться. Выдержка из Найробского договора должна совпадать с полным подпунктом (4). [Проверка без вызова модели](check_evidence.py)

В 7 положительных вопросах сервис вернул отказ. Для 6 из них в переданном модели контексте присутствовали все эталонные выдержки. [Стадии и события самих запросов](observed-refusals.json)

## Пересчёт

Запустите из корня репозитория. Для сверки исходных PDF используются зависимости приложения, Poppler и Tesseract с русским и английским языками. Языковые данные можно указать через `TESSDATA_PREFIX`.

```sh
report="$PWD/eval/reports/published-final"
export B1_EVAL_PACK=published-six
export B1_EVAL_WORK_DIR=$(mktemp -d)
tar -xzf "$report/inputs.tar.gz" -C "$B1_EVAL_WORK_DIR"
mkdir -p "$B1_EVAL_WORK_DIR/runs/final"
cp "$report/manifest.json" "$report/responses.jsonl" "$report/claim-review.json" "$B1_EVAL_WORK_DIR/runs/final/"
uv run --frozen python eval/qualification_data.py --check-index
uv run --frozen python eval/metrics.py --run final
uv run --frozen python "$report/check_evidence.py" "$B1_EVAL_WORK_DIR"
uv run --frozen python eval/qualification_review.py score --run final
```

Снимок содержит эталон, список документов и шесть экспортов с каноническим текстом, идентификаторами фрагментов и страницами. [Снимок входных данных](inputs.tar.gz) · [SHA-256 артефактов](sha256.json)

Чтобы заполнить собственную разметку, используйте отдельную рабочую папку с манифестом, ответами и пересчитанными метриками. Выполните `uv run --frozen python eval/qualification_review.py prepare --run final`. Файл `runs/final/claim-review.json` будет связан с точными текстами ответов и эталоном.
