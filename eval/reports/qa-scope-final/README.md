## Сохранились ли прежние полные ответы

В архиве `balanced` найдены 135 уникальных положительных вопросов с ранее подтверждённой полнотой. Для каждого взят последний полный ответ на тот же вопрос по тому же PDF или DOCX. Модель-судья сверила все обязательные факты, применимые условия и смысловую поддержку каждого утверждения в новом ответе.

| Ответ неполный или не полностью подтверждён | 3 |

В 1 случаях модель отметила критическую смысловую проблему. Сюда входит пропуск обязательного условия в выданном ответе.

В `contract-04-02` прежний ответ сохранил грузоподъёмность 3 т из пункта 1.1, относящегося к арендуемому помещению. Новый ответ соединил 1,5 т из акта с условием аренды из пункта 1.1. Для пересчёта распакуйте `inputs.tar.gz` в рабочий каталог, скопируйте `responses.jsonl` и `manifest.json` в его `runs/final/`, задайте `B1_EVAL_WORK_DIR` и запустите `uv run --frozen python eval/metrics.py --run final`. [Инструкция живого прогона](../../README.md)

После человеческой сверки независимого набора сохраните заполненный шаблон как `runs/final/claim-review.json` в отдельном рабочем каталоге. Укажите имя в `reviewer` и значение `human` в `reviewer_type`. Для подсчёта нужны Poppler и Tesseract с языками `rus` и `eng`. Запустите `B1_EVAL_PACK=independent-ten uv run --frozen python eval/qualification_review.py score --run final --source-review /путь/к/заполненному-листу.md`. Результат сохранится в `runs/final/qualification.json` этого рабочего каталога.
