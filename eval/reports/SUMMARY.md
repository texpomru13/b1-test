## Сводка (итог этапа 9)

### Условия

- Машина: macOS Apple Silicon (M4 Max), host Ollama 0.40.16.
- Стек: отдельный compose-проект `b1-eval`; проект по умолчанию `b1-rag` и его volumes не затрагивались.
- Профиль **balanced**: Giga-Embeddings-instruct-480M + bge-reranker-v2-m3 + qwen3.5:9b-q4_K_M.
- Судья: локальная qwen3.6:27b-q4_K_M. Платных вызовов API не было.
- Gold-набор: 133 вопроса, составленных агентом (93 с ответом, 40 без ответа), и 17 проб изоляции (вопрос к чужому документу).
- Разбиение по документам: dev — 01, 05, 13, 15; holdout — остальные 10.

### Что выполняется во всех прогонах

- Валидность цитат 100%: каждая цитата — точная подстрока канонического текста, смещения восстановлены сервером.
- Утечка цитат из другого документа: 0.
- Ответы 200 валидны по схеме на 100%. Единственный невалидный ответ был до коммита a69d620 и исправлен.
- Доказательство среди кандидатов поиска: hit@60 = 93/93.

### Ложные срабатывания

Это found=true на вопросе без ответа. Каждый случай судья разбирал по проверенным цитатам.

- **t0:** 1 случай (10-09). Цитаты на вопрос не отвечают, то есть это галлюцинация.
- **Вариант «рассуждение off»:** 3 случая (01-07, 08-07, 10-09).
- Ни одна проба изоляции ни разу не вернула found=true.

### Почему терялись ответы

Разбирались 29 промахов варианта «рассуждение off»: каждый вопрос задан повторно с захватом логов (`miss_diagnosis.jsonl`).

| Причина | Случаев |
|---|---|
| Цитата модели не точная подстрока канонического текста, проверка происхождения дала отказ | 18 |
| При повторном вопросе ответ найден (шум сэмплирования) | 9 |
| Отклонил верификатор | 2 |

Классы отклонённых цитат лежат в `eval/reports/diagnosis/`. В основном это пробелы внутри слов в тексте PDF и фрагменты, склеенные многоточием; их исправило сопоставление цитат v2. Шум сэмплирования исправила temperature 0. Оставшиеся 14 промахов t0 повторно не разбирались (`not_run`).

### Поиск

Метрики посчитаны по gold-фрагментам на опубликованном индексе, сплит «все».

| Метод | recall@8 |
|---|---|
| Гибрид RRF + реранкер | 0.968 |
| Только dense | 0.964 |
| Гибрид RRF без реранкера | 0.943 |
| Только BM25 | 0.863 |

У гибрида с реранкером также all-spans@8 0.968, hit@60 1.0 и nDCG@10 0.938. Именно реранкер выводит гибрид выше dense на top-8.

**Энкодеры.** Dense recall@8 на одних и тех же фрагментах: Giga-3B 0.975, Giga-480M 0.964, BGE-M3 0.931. 480M кодирует примерно в 8 раз быстрее 3B.

**Реранкеры.** Оценка на замороженных top-60 кандидатах, метрика all-spans@8: bge-reranker-v2-m3 0.968, Qwen3-Reranker-0.6B 0.935–0.946 при работе в 7 раз медленнее.

**Qwen3-Reranker-8B — `not_run`.** В fp32 на MPS он занял около 100 ГБ общей памяти, swap дошёл до 39 из 40 ГБ, и за 2 ч 26 мин прогон не завершился. Его остановили, чтобы не повесить машину.
