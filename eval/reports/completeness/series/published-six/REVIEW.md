# Полнота ответов по официальным публикациям

В контрольной серии по шести PDF ассистент OpenAI Codex сверил все 25 ответов с вопросами, источниками и заранее зафиксированными критериями. Полными стали **9 из 14** ответов, в которых при приёмке обнаружили пропуски. Среди случайно выбранных полных ответов сохранили полноту **11 из 11**. [План отбора](../../plan.json) · [Оценка каждого утверждения](claim-review.json)

Сервис вернул 24/25 структурных ответов и выдал содержательный текст в 23 случаях. По всем 25 вопросам вместе передано 42/47 обязательных элементов. Все 44 цитаты совпадают с соответствующими фрагментами исходных документов по тексту, странице и координатам. [Ответы API](responses.jsonl) · [Результаты и знаменатели](result.json)

В space-01 все четыре параметра орбиты перечислены верно. Если считать дословно добавленное соседнее требование о дате и месте запуска допустимым пояснением, число исправленных ответов увеличится на один. Основной итог использует строгую оценку релевантности каждой части ответа. [Фактический текст](responses.jsonl)

## Подтверждённые ответы

По Европейской конвенции возраст кандидата связан с датой, к которой список направляют в Парламентскую ассамблею. По Протоколу № 16 названы ограничение запроса конкретным делом и оба адресата публикуемого заключения. Результаты всех шести положительных и четырёх отрицательных вопросов по этому PDF, с указанием фактически повторённых, приведены отдельно. [Разбор ЕКПЧ](ECHR.md)
