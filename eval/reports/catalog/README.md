## Материалы и пересчёт

Сводный файл содержит число случаев для каждого документа и хэши плана и манифестов. Команда сверяет вопрос, целевой документ, отсутствие повторов и идентичность работающего приложения для всех четырёх серий. [Смысловая сверка 30 договорных ответов](numbered-review.md) · [Сводные данные](coverage.json) · [Договоры организаций](../contracts/README.md) · [Официальные публикации](../published-final/README.md) · [Оферты и тарифы](../offers/README.md)

```sh
uv run --frozen python eval/acceptance.py
```

В этом каталоге сохранены [30 ответов по пронумерованным документам](responses.jsonl), их [манифест](manifest.json) и [контрольные суммы](sha256.json).

Для пересчёта механических метрик на сохранённых HTTP-ответах из корня проекта выполните команды.

```sh
export B1_EVAL_WORK_DIR="$(mktemp -d)"
REPORT="$PWD/eval/reports/catalog"
tar -xzf "$REPORT/inputs.tar.gz" -C "$B1_EVAL_WORK_DIR"
mkdir -p "$B1_EVAL_WORK_DIR/runs/numbered"
cp "$REPORT/responses.jsonl" "$REPORT/manifest.json" "$B1_EVAL_WORK_DIR/runs/numbered/"
uv run --frozen python eval/metrics.py --run numbered
```
