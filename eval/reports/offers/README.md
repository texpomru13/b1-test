Один предшествующий запрос по договору аренды прогрел модели и исключён из расчёта времени и долей. Версии моделей поиска и переранжирования, параметры генерации и аппаратная конфигурация сохранены в [манифесте](manifest.json).

## Как пересчитать результаты

В корне репозитория подготовьте окружение командой `uv sync --frozen`. Затем выполните пересчёт с отключённым сетевым доступом `uv`.

```sh
uv run --offline --frozen python eval/reports/offers/replay.py
```

Скрипт проверяет SHA-256, распаковывает снимок индексов во временный каталог и сверяет эталоны с шестью PDF и с текстом опубликованных индексов. Затем он заново рассчитывает показатели по сохранённым HTTP-ответам и вердиктам обоих проверяющих. Побайтово сверяются результаты по запросам, технические показатели, оценка модели и дополнительная проверка полноты. Для пересчёта нужны Python, зависимости из `uv.lock` и файлы репозитория.

- [Манифест сборки, настроек, моделей, индексов и замера](manifest.json) · [Прогрев](warmup.json)
- [Ответы с вопросами, признаками отказа, цитатами и временем](responses.jsonl) · [Технический результат по каждому запросу](cases-all.jsonl) · [Сводные показатели](metrics-all.json)

## Бланк для независимой сверки

[Лист сверки](../../packs/external-six/source-review.md) ведёт от каждого вопроса к странице PDF и содержит поле для имени и отметок. Чтобы проверить те же HTTP-ответы, создайте отдельный рабочий каталог и заполните полученный файл `claim-review.json`. Инструкция к полям и значениям вердиктов приведена в [руководстве по оценке содержания](../../README.md#оценка-содержания).

```sh
report="$PWD/eval/reports/offers"
export B1_EVAL_PACK=external-six
export B1_EVAL_WORK_DIR=$(mktemp -d)
tar -xzf "$report/inputs.tar.gz" -C "$B1_EVAL_WORK_DIR"
run="$B1_EVAL_WORK_DIR/runs/final"
mkdir -p "$run"
cp "$report/manifest.json" "$report/responses.jsonl" "$report/metrics-all.json" "$run/"
uv run --offline --frozen python eval/qualification_review.py prepare --run final
uv run --offline --frozen python eval/qualification_data.py --source-sheet "$B1_EVAL_WORK_DIR/source-review.md"
```

После заполнения сохраните оба файла и выполните `uv run --offline --frozen python eval/qualification_review.py score --run final --source-review "$B1_EVAL_WORK_DIR/source-review.md"`. Команда запишет результат независимой проверки в `$B1_EVAL_WORK_DIR/runs/final/qualification.json`.
