## Что было пустым

Сценарий проверил чистое рабочее дерево отдельного клона, отсутствие контейнеров и томов проекта `b1-release1121`. Для Ollama он создал каталог `OLLAMA_MODELS` и запустил отдельный процесс на порту 11593. До старта API список Ollama был `{"models":[]}`. Для Hugging Face сценарий создал новый пустой `HF_HOME`. Launcher смонтировал свой `empty-seed` как источник для копирования весов.

Журнал Ollama зафиксировал успешный `POST /api/pull` длительностью 8 мин 30 с. Затем `models-init` скачал обе закреплённые ревизии с первой попытки, записал манифест и завершился с кодом 0. Публичный `GET /health/ready` вернул `ready`, `model_ready=true` и `ok` для Redis, Qdrant, сервиса энкодера и реранкера и LLM. Хеш `/health/build` совпал с хешем API из проверенного checkout.

На машине уже были образы и слои Docker. В журнале сборки 18 шагов с отметкой `CACHED`. На машине с пустым хранилищем Docker добавятся загрузка и сборка недостающих слоёв. Для такого окружения нужен отдельный замер времени и трафика.

После `./run stop` и `./run --offline` API вернул оба документа с прежними идентификаторами и `ready=true`. Отдельный запрос документа аренды подтвердил 10 страниц и 93 фрагмента. В журнале повторного `models-init` обе модели отмечены как уже присутствующие. В конфигурации с хостовым Ollama флаг `--offline` использует локальные веса и образы. Сеть Docker в этом профиле остаётся открытой для связи с Ollama на Mac.

## Повторение

Нужны macOS с запущенным Docker Desktop, исполняемым `ollama`, командами `git`, `jq`, `curl`, `nc` и доступом к сети для первой загрузки. Из клона репозитория запустите сценарий с двумя свободными локальными портами, сначала для Ollama, затем для API.

```sh
sh eval/reports/cold-start/reproduce.sh 11594 65146
```

Сценарий выберет новое имя Compose-проекта, подготовит отдельные каталоги и checkout точного коммита, выполнит команды запуска и публичного демо, остановит сервисы командой `./run stop`, запустит их из сохранённого кэша и проверит доступность документов. В конце он напечатает путь к журналам и JSON-ответам. Созданные модельные каталоги и именованные тома доступны для последующей проверки.
