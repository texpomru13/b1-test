# Диагностика цитат

В файлах этой папки собраны отклонённые фрагменты ответов и причины расхождения с текстом документов. Среди причин встречаются внутрисловные пробелы в текстовом слое PDF и фрагменты, соединённые многоточием. Журналы помогают отличить ошибку сопоставления текста от нехватки доказательств. [Проверка отказов по вопросам](../refusal-review.md)
