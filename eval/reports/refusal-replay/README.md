# Ответы при фиксированном контексте

Для 13 вопросов по договорам из журнала отказов сохранили те фрагменты, которые система передала генератору в этих запросах, вместе с их порядком, координатами и страницами. Локальная Qwen получает вопрос и эти фрагменты. Затем сервис выбирает подтверждение для каждого утверждения, проверяет ответ и восстанавливает цитаты. Такой эксперимент позволяет отдельно оценить, какие сведения модель может извлечь из уже подобранного текста. По критерию покрытия не менее 80% длины каждой эталонной выдержки в десяти случаях поиск нашёл все выдержки. В трёх отсутствует нужный пункт.
